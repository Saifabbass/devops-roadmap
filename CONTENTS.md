# Course files

- `index.html`: complete offline course viewer.
- `handbook/`: beginner setup, concepts, specification and operational guidance.
- `teaching/lessons/`: all 52 authored guided lessons.
- `teaching/repository-synthesis.json`: in-course teaching from all 40 reviewed repositories.
- `labs/taskboard/`: starter, staged reference implementation, tests, migrations, Compose and CI examples.
- `labs/delivery/`: private staging deployment and rollback helper.
- `downloads/dev-opps-labs.zip`: clean lab download for website learners.
- `research/`: source inventories, repository assessments and roadmap investigation.
- `templates/`: evidence, incident, decision, runbook and readiness templates.
- `assets/`: local font, mascot SVGs, static alternatives and existing montage exports.
- `redesign-source/`: current visual modules.
- `tools/`: repeatable builder, validators and packager.
- `Dev-Opps-Public-Site.zip`: static hosting package; upload the contents of `site`.
- `Dev-Opps-Complete-Course.zip`: portable source edition; extract before opening.
- `PACKAGE-MANIFEST.json` and `MANIFEST.sha256`: package and file checksums.

Local author backups and lab caches are excluded from the public packages. `DevOps-Engineering-Fieldbook.zip` is an older historical archive; use the new Dev-Opps archives above for the expanded course.
